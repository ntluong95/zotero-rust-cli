# Phase 8: ASK wrapper fixes

## Goal

Make ASK's `ask-zotero` wrapper deduplicate records by identifier correctly, probe Better BibTeX on
the right port, and describe the CLI accurately.

## Context

- **Repo:** `~/agent-science-kit` (remote `ntluong95/agent-science-kit`). Edit
  `skills/ask-zotero/`. `ask-portable/` is gitignored build output generated by
  `cli/internal/emit/portable.go`, so do not edit it.
- **Installed copy:** `~/.claude/skills/ask-zotero`, currently byte-identical to the source.
- **Dedupe lookup:** `findExistingRecord()` (`scripts/zotero.mjs:1151`) runs `item find <id>` with
  the default `--scope titleCreatorYear`, which never matches a DOI (live: 0 hits; with
  `--scope fields`: 1 hit). The result is duplicate imports of PMID, arXiv, and URL records, and
  DOI records misreported as `imported`.
- **BBT port:** `bbt-probe` falls back to port 23119, but this Zotero listens on 23120.

## Files

- Modify: `~/agent-science-kit/skills/ask-zotero/scripts/zotero.mjs`.
- Create: `~/agent-science-kit/skills/ask-zotero/scripts/zotero.test.mjs`, following the
  `*.test.mjs` convention used in `ask-citenet` and `ask-litreview-deep`.
- Modify: `~/agent-science-kit/skills/ask-zotero/references/api-surface.md` to replace "RC2" with
  "v1.1+" and note that reads now work while Zotero is running when the Bridge is healthy.
- Modify: `~/agent-science-kit/skills/ask-zotero/SKILL.md` only if the contract text changes.

## Steps

1. In `findExistingRecord()`, call
   `["item", "find", query, "--scope", "fields", "--limit", "50"]`. Keep the exact-identifier
   filter (`exactIdentifierMatch`) as the authority.
2. In `ingestRecord()`, treat an `add doi` payload whose `status` is `already_exists` as `reused`,
   not `imported`.
3. In `derivePort()`, fall back to `zotero-cli --json app status` → `.port` before using 23119.
4. In `bbtProbe()`, report `available: true` only for HTTP 200 with a JSON-RPC body, and keep the
   raw response for diagnosis.
5. Add unit tests that stub `ZOTERO_CLI_BIN` with a fake script:
   - the scope flag is passed;
   - `already_exists` counts as reused;
   - the port is derived from `app status`.
6. Reinstall the skill using ASK's own installer or emit path, not a hand copy. Confirm that the
   installed file matches the source.

## Verification

- `node --test skills/ask-zotero/scripts/zotero.test.mjs` from `~/agent-science-kit`.
- Live: `node scripts/zotero.mjs bbt-probe` reports port 23120.
- Live: `node scripts/zotero.mjs find --query "10.1016/S2542-5196(24)00273-0" --library 1`
  returns `8CGMWH6E`. This needs Phase 2's `session use-library` fallback when Zotero is running.
